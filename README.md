# BowlsEmpren — Montero's Bowls

Landing page estática de Montero's Bowls (La Dorada, Caldas).

## Estructura

```
index.html     # Landing page (HTML + CSS + JS en un solo archivo)
netlify.toml   # Configuración de despliegue en Netlify
```

## Ejecutar en local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
npx serve .
```

## Desplegar en Netlify

- **Build command:** (vacío)
- **Publish directory:** `.`

Netlify sirve `index.html` automáticamente como página principal.
